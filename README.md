# Vishudh Agro

A Flask-based agro products website with static assets, templates, and email enquiry support.

## Setup

1. Create a Python virtual environment.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Update the values in `.env` for email delivery.
4. Run the app:
   `python app.py`

## Structure

- `app.py` – Flask entry point
- `templates/` – HTML pages
- `static/` – CSS, JS, images, icons
- `utils/mail.py` – email helper
